# 设计与实现说明

## 1. 美术方向

**日式 lofi 小书房，三渲二。** 暖色、低对比、柔和泛光，像一帧安静的动画背景。

- 色板：蜂蜜色橡木桌、米色灰泥墙、木色柱与长押；打字机薄荷绿 `#8fcdb7` + 奶油 `#f6ecd3` + 镀铬 + 黄铜点缀；植物两档绿、陶盆橘、花朵粉红；线条暖棕 `#3a2418`（夜晚换成深蓝紫）。
- 构图：桌子靠后墙，窗在左墙。房间在四楼，窗外是一张“动画背景”式的街景：对街的人家和咖啡馆、樱花行道树、成片的瓦屋顶、高架上偶尔驶过的电车、五重塔和富士山。太阳从窗外照进来，光斑和窗格影子斜铺在桌上，打字机处在光里；默认相机在打字员右后方，左上角是樱花窗，右边是书架与浮世绘。
- lofi 摆设：唱片机、靠墙的唱片封套、霓虹灯牌（月亮 + “夜ふかし”）、熔岩灯、吊在窗边的绿萝（麻绳吊篮）、书架下的紫色灯带、软木板上的拍立得，和墙上悬浮的玻璃音乐播放器。
- 三种光线：午后（暖阳 + 光柱 + 浮尘）、黄昏（低角度橙光、台灯和串灯亮起）、夜晚（蓝色月光 + 暖色台灯）。

## 2. 渲染管线（`src/engine/toon.js`）

1. **卡通材质**：`MeshToonMaterial` + 8 级阶梯渐变图（暗部 / 明暗交界一档 / 亮部），通过 `onBeforeCompile` 加入：
   - 硬边高光：Blinn-Phong 高光经 `smoothstep` 截成一块亮斑（金属、搪瓷、键帽）；高光乘以光源颜色，阴影里的光源不会产生高光；
   - 轮廓光：视线掠射处的一圈暖白边，在受光面更强。
2. **描边后期**：用 `MeshNormalMaterial` 覆盖渲染一遍视空间法线和深度（只渲染第 0 层），再在合成着色器里找边：
   - 深度用 `1/z` 的拉普拉斯——平面在屏幕空间里 `1/z` 是仿射的，所以斜着看的桌面、墙面不会出假线，只在轮廓和折角处出线；
   - 法线差 > 阈值出线；对着空背景的轮廓单独补线；
   - 线条颜色随底色调制，远处渐隐。光柱、浮尘、蒸汽、天空、玻璃、窗外的绘制层、花团卡片、霓虹和播放器放在第 1 层，不描边（绘制层自带线条）。
3. **泛光**（阈值 1.05，只有窗外天空、灯泡、串灯等最亮处发光）→ **OutputPass**（Neutral 色调映射）→ **调色**（提亮暗部、暖高光、轻暗角、细颗粒）。
4. 阳光：一盏带 4096 阴影贴图的平行光放在窗外；左墙是带窗洞的真实几何体，所以光只能从窗口进来；窗前那棵樱花（近景花团才投影）在桌上投下花影。光柱是沿光线方向、在顶点着色器里朝向相机展开的带状面片，**正对着看时自动变淡**（否则朝窗看时多条光柱叠加会把窗外冲成一片白）；浮尘粒子在顶点着色器里沿太阳方向反推到窗所在平面，只有落在窗口矩形内的才可见。
5. 窗外大部分是“画”出来的（见第 7 节）：绘制层用自己的着色器按时段整体调色（色调、雾色、夜晚灯光），三维的电线杆、樱花枝和花瓣仍用卡通材质，会被房间的光照到。

## 3. 打字机与机械动作（`typewriter.js`、`geometry.js`）

坐标：x 向右，y 向上，z 朝向打字员；桌面 y = 0；1 单位 ≈ 4.8 cm。

- **打印点**固定：压纸辊轴 (y 3.12, z −1.42)，半径 0.43；打印点在辊面朝前略偏上 7°。所有部件从这一组常量推导。
- **字篮**：42 根字杆的转轴排在以打印点为圆心（俯视）的半圆上（半径 1.02，低于打印点 1.08）。静止时字杆向外略向下躺在毛毡托上；击打时绕各自转轴的切向轴转动 `swing`，转到“转轴 → 接触点”的方向。字锤按撞击姿态斜装，撞击时字面与纸面平行。数值检查：42 个字锤落点 x ∈ [−0.03, 0.03]，y 完全一致。
- **键与字杆的对应**：按键盘位置从左到右分配字杆，键杆/拉杆从键下连到字杆根部。大写和上档符号用同一根字杆并让字篮下沉（segment shift）。键盘外的字符（中文等）借用一根固定的字杆，属于数字扩展。
- **时间曲线**（调校值，按 `k` 缩放）：字杆 50 ms 加速上扬 → 12 ms 接触 → 130 ms 回落并轻微回弹；色带抬起器先于字杆抬到纸前，接触后落下；按键 50 ms 按下、弹簧式回弹；松键后擒纵放行，小车走一格。连续输出时 `k` 最小降到 0.38。
- **小车**：只沿 x 平移；打字时向左（操作者视角）一格一格走（ω = 70 的阻尼弹簧），退格向右一格，回车时超过 2.5 格的向右滑行（ω = 15，先拉回车杆再滑），到位时播放撞停声。行末前 8 格响铃。
- **进纸**：压纸辊转角 = 纸在路径上的移动量 / 半径（纸随辊面一起走，不打滑）。

## 4. 纸张（`geometry.js`、`paper.js`、`ink.js`）

- **路径**：以弧长 s 参数化（s = 0 为打印行）：
  - 绕辊段：从辊后下方（−142°）绕过辊底到前面，经过打印点到压纸杆（38°）；
  - 前方自由段：从压纸杆处沿切线离开，在 2.8 单位内平滑后仰到 36°，再往上按 (1 − 挺度) 增加后仰（超出纸托后下垂）；
  - 后方段：沿纸托斜面向上，超出纸托后同样下垂。
  - 路径按 0.02 步长预积分成查表，所以 **弧长严格保持**（测试：任意 0.01 步长误差 < 2%），纸不会被拉长，也不会穿过压纸辊和桌面（测试覆盖三档挺度）。
- **网格**：14 × (高度 / 0.035) 细分；每一行顶点按其到上边缘的距离 v 放在 s = sTop − v 处，法线直接取路径法线。文字在纸的贴图里，所以**文字永远绑在纸的坐标上**，随曲面弯曲。
- **版面**：字宽 0.08、行高 0.16（2:1，相当于 pica 10/6 的比例放大），左右边距对称、上边距 0.5。A4 46 × 33，16:9 66 × 15，1:1 46 × 21。打印行中心落在 s = 0。
- **墨迹**：每个字有稳定的微小位移/旋转/浓淡（按纸页种子和行列哈希），叠一层很淡的偏移“二次压印”，再用颗粒图案擦掉一些像色带磨损；墨层与纸层分开，用正片叠底合成；只重绘受影响的格子。
- **换纸**：继续送纸直到下边缘越过压纸杆 → 抽出：刚体框架沿抽出方向提起、沿二次贝塞尔弧线飞到桌边、四元数插值转平，局部形状从机内的弯曲形状插值到带轻微卷边的平纸，落下时有一点“空气垫”。新纸从纸托上卷入。连续输出导致一次满好几页时，中间几页直接叠到纸堆上。

## 5. 终端语义与同步（`pages.js`、`mechanism.js`、`experience.js`）

- xterm 是唯一的终端状态：输入经 `onData` 发出（演示 shell 或 SSH），输出用 `term.write` 交给 xterm，纸面只读取 **已解析** 的缓冲区单元格（`getCell / getChars / getWidth`、颜色、粗体、斜体、暗淡、下划线、反色、隐藏、删除线），宽字符占两格，`width = 0` 的占位格跳过。
- **纸页**：当前纸页 = 从 `pageTop` 开始的 `rows` 行，`pageTop` 用 xterm marker 追踪（回滚裁剪不会让它错位）。光标越过最后一行 → 整页复制成普通对象归档（不保存 xterm 的可复用 cell 对象）。`ESC[2J`/`ESC[3J` 在 normal 缓冲区通过 `parser.registerCsiHandler` 在擦除前归档并换纸（2 秒内重复清屏视为普通的数字擦除）。
- **击打队列**：每帧最多比较一次“已上墨”与“已解析”：空白格变成可见字符 → 进入击打队列（按阅读顺序）；其他变化（擦除、覆盖、改色）立即改纸面。队列头决定小车和走纸的目标位置，到位后击打，**墨迹在接触时刻才画上**。
- **延迟上限**：排队超过 160 格或最早的字等待超过 0.9 s → 立刻全部上墨，只抽样播放几下快速击打，小车直接追到位。所以大量输出不会形成无界的视觉延迟，也不会丢任何终端数据（终端本身从不等待动画）。
- **alternate 缓冲区**：根据 `buffer.active.type` 判断；进入后暂停逐字击打与换纸，全屏画面直接显示在这张纸上（见第 8 节），原来的纸页内容先保存；退出后恢复 normal 缓冲区的纸页内容和纸张网格。
- **输入法**：xterm 的 textarea 始终挂载且有真实尺寸；组字中的拼音以铅笔色画在纸面光标处（不归档）。

## 6. 声音（`sound.js`）

全部在第一次用户操作时用 JS 算出 AudioBuffer：

| 声音 | 做法 |
|---|---|
| 字杆击打 | 1 ms 宽带冲击 + 2.3–2.9 kHz 带通噪声（τ≈11 ms）+ 190 Hz 橡胶辊“闷响”+ 3–7 kHz 金属分音；+35 ms 键回弹、+50 ms 擒纵“嗒”。8 个随机变体，播放时 ±4% 变速、±10% 音量 |
| 空格 | 118 Hz 宽杆闷响 + 760 Hz 嘎嗒 + 擒纵声 |
| 换行 | 两下棘轮 |
| 回车 | 回车杆棘轮三连 → 低频滑行噪声 + 棘爪划过齿条的加速连响（90→260 次/秒）→ 撞停：88 Hz 闷响 + 1.4/2.3/3.7 kHz 金属余振 |
| 铃 | 2420 Hz 基音 + 近似钟的非谐分音（×2.32、×4.25、×6.63），带一点拍频 |
| 卷纸 / 抽纸 | 旋钮棘爪细响 + 高通噪声的纸张摩擦声 |
| 环境 | 风铃（与风铃摆动同步）、偶尔的鸟叫、极轻的房间底噪 |

经过 0.6 s 生成式混响（小房间）与压缩器。机械音量、环境音量、静音分别可调。**所有音色都是合成的，不是实机录音。**

## 7. 窗外：画出来的街景（`street.js`、`paint.js`）

第二版用三维盒子拼出来的街道，从窗口看出去只是一堆错乱的屋顶和粉色团块。这一版改成动画背景的做法：**分层绘制 + 视差**。

- **绘制层**：几张以窗外一点为圆心的圆柱面（半径 380 / 650 / 1300 / 2400 / 3300），各自贴一张用 Canvas 2D 程序绘制的画。画笔在“世界单位”里画：横向是圆柱上的弧长，纵向是世界高度。相机在房间里移动时，近层和远层的相对位置自然变化，就有了景深；每层按 1–2° 分段，常用视角（向右 −12°…74°）每度 30 像素，侧面更粗。
- **房子是投影出来的**：每栋房子是一个极简的三维模型（正立面、出檐的坡屋顶或平顶、阳台），顶点通过窗外那一点投影到圆柱上再画，所以每一排房子的透视都对：从四楼看过去，近处能看到阳台和晾的衣服，远处只剩屋顶。屋顶类型有顺坡双坡、四坡、山墙朝街、平顶（水箱、楼梯间）；细节按投影后的像素宽度分三档：瓦垄线、屋脊和鬼瓦、封檐板、檐下阴影、落水管、推拉窗（窗框、反光、中梃、半拉的窗帘）、阳台栏板、空调外机、晾衣杆上的衬衫和毛巾、搭在栏杆上的条纹被子、花箱、天线、太阳能板、阳台上的黑猫。
- **层次**：对街七户（四层公寓、黑色板壁的老屋、晾被子的人家、山墙朝街的“珈琲”咖啡馆、带太阳能板的两层楼……）→ 两层成片的屋顶（12 + 5 排，越远越淡、越蓝）→ 高架铁路（一列 4 节的电车约每 40 秒驶过一次，方向交替）、澡堂烟囱、神社的鸟居和树丛、五重塔 → 远处的城市（几排中高层，右侧一簇高楼，左边一座红白铁塔）→ 富士山（积雪带沟壑状的“雪指”，右侧背光面）和远山（山脊上一排树冠）→ 天空。
- **天空**：着色器穹顶，云是三档卡通明暗的积云纹理（R 通道存明暗档，A 存覆盖），按时段换成白/桃色/夜蓝；太阳或月亮带光晕，夜晚有闪烁的星。
- **樱花**：真正三维的只有樱花树——枝干是带锥度的卡通材质管子（有描边），花团是**始终面向相机的绘制卡片**（四种花团画在一张图集里：一簇簇小圆瓣、三档粉色、亮面上的五瓣小花、暗部的花蕾、伸出来的小枝），用实例化渲染、alpha-to-coverage 抗锯齿，并随风轻摆。对街一排行道树的树冠在窗下铺成一片粉色；院子里那棵老树的树冠在窗户上方，把花枝伸到窗前。
- **电线杆和电线**：两排水泥杆（横担、绝缘子、变压器、路灯臂），相邻电杆间按悬链线拉电线，另有通信缆和接到我们这栋楼的入户线——这是日本街景最典型的一笔。
- **时段**：午后原样；黄昏整体偏暖、远处加橘粉色的雾；夜晚整体压暗偏蓝，窗户、咖啡馆招牌、铁塔和电车车窗亮灯（单独的灯光贴图），路灯亮起，樱花被打亮成“夜樱”。
- 花瓣：320 片实例化花瓣从树上飘落；我们这面墙只有半开的窗扇能让花瓣通过，进来的花瓣落在窗台或桌面左侧，约 40 秒后淡出。

## 8. 全屏程序：直接显示在纸上（`paper.js`、`magic.js`）

- 触发：xterm 的缓冲区切换到 alternate（`buffer.onBufferChange`），与程序名无关；退出时由切回 normal 触发。
- 不再单独弹出一张“魔法纸”：**就在打字机里那张纸上**显示。进入时把当前纸页的击打队列冲刷完，暂停逐字击打；按 1:2 的格子比例把整个屏幕排进纸的文字区（居中），往上送纸让整块屏幕露在压纸杆上方，相机正对这块区域。退出时恢复原来的纸页内容、纸张网格和相机。
- 尺寸：默认把终端临时放大到至少 80×24（btop 的最低要求；A4 时为 80×33），并同步给 SSH 的 PTY。
- 画法：每秒最多读 30 次（同步输出模式期间不读），只重画签名变化的格子。颜色转成“纸上的墨”：亮度压到 118 以下、饱和度略提，背景色只是一层淡淡的水彩；反色格子用墨色铺底。制表线、方块元素、盲文点阵按格子用矢量画满，btop 的边框和曲线连续。光标按程序的显示/隐藏画成竖线。
- 魔法：变化的格子在一张 cols×rows 的亮度纹理里点亮再衰减，纸张着色器让**墨迹本身**泛出琥珀金色（纸面只有一圈很淡的暖光），亮度压在泛光阈值以下，跳动的数字仍然清楚；同时从格子的三维位置冒出几点星光。整屏重绘时只微亮，小范围更新才明显。

## 9. 猫（`cat.js`）

自己画的 Q 版橘色虎斑：大而圆的“麻薯”脸（一个球体按脸颊鼓起、底部压平），头靠在两只奶油色前爪上；额头三道“川”字纹、脸颊各两道、背上一排横纹都是画在贴图上的；闭着眼的 ◡ ◡、ω 嘴、粉鼻头、腮红、几根胡须单独叠在脸上并且不描边；红色项圈挂着小铃铛；尾巴绕到身前，尾尖奶油色会慢慢摆。头和身体各是一整个网格，所以描边只出现在外轮廓。它会呼吸，偶尔抖一下耳朵，头顶飘着淡淡的“z”；打字机行末铃响时会抬一下头、竖起耳朵。

## 10. 墙上的画与音乐

- **换成你的图片**：三幅浮世绘和软木板上的三张拍立得都是“画框位”。点墙上的画（悬停有提示）或在设置里点“换图”选择图片 → 按画框比例居中裁切（最长边 1600 px）→ 贴到画框上；裁好的 JPEG 存在本机浏览器的 IndexedDB，下次打开自动恢复；“恢复”换回原画。
- **音乐**：工具栏“音乐”或点墙上的播放器打开抽屉，添加本地音频文件（可多选）。播放列表（文件本身）存在 IndexedDB，刷新后恢复但不自动播放。一个 `<audio>` 经 Web Audio（MediaElementSource → Analyser → 音量）接到单独的音乐总线：不受机械音量和压缩器影响，静音时一起静音；播放时页面切到后台也不会暂停。支持列表循环/单曲循环、上一首/下一首、拖动进度。
- **悬浮播放器**：墙上一块磨砂玻璃卡片（Canvas 绘制、每秒最多重绘 30 次）：旋转的唱片（标签颜色按曲名取）、滚动的曲名、32 段柔和渐变的频谱、进度和时间、五个按钮；后面一圈粉紫光晕、周围环绕闪烁的星点（随音量更活跃），播放时飘出音符；整块卡片缓缓上下浮动。点击按卡片的 UV 换算成按钮。
- **唱片机**：播放时唱臂摆到唱片上、转盘按 33⅓ 转/分钟转起来（暂停时慢慢停下）、电源灯变绿。
- 霓虹灯牌、书架灯带、熔岩灯的亮度随时段变化：白天很淡，夜晚最亮（配合泛光）。

## 11. 遮挡与输入法

- 打印点附近：字导的 U 形导板和桥架都在打印行下方；卡纸指与压纸杆上的刻度尺改为透明塑料（只有刻度和一条红色对位线不透明）；色带静止时比打印行低 0.33（约两行）。当前行和上一行都能完整看到。
- **无遮挡视图**：工具栏“无遮挡”按钮把纸前的字导、卡纸指、压纸杆和滚轮、色带及色带抬起器整个隐藏，纸面完全露出来；设置会被记住。键盘上原来的 Tab 键在近距离会和机身穿模，已去掉（退格键挪到那一排的末尾）。
- 系统输入法候选框：浏览器把它放在获得焦点的输入框旁边。xterm 的输入框始终挂载在（不可见的）终端面板里；聚焦且面板关闭时，每 150 ms 把面板平移到让输入框正好落在“打印点在屏幕上的投影”下方 22 px 处，候选框就出现在正在打的那一行下面。
- 标准终端面板停靠在右侧（窄屏在底部）。三维相机用 `setViewOffset` 把主点移到未被遮挡区域的中心，并保持同样的像素尺度，打字机始终在可见区域中间；关闭面板时平滑移回。

## 12. 性能

- 静态零件按材质合并；花团卡片、花瓣用实例化；窗外的街景是几张贴图而不是成百上千的几何体。42 根字杆的杆体/字模、45 个圆键的键环/键杆改为 4 组实例渲染，打字机网格由 301 个降为 131 个，投影对象由 210 个降为 84 个，三角形和原有机械轨迹保持不变；休止的零件不重复上传实例矩阵。花瓣循环复用向量，避免每帧数百次临时分配。
- 纸面贴图只在有变化的那一帧上传一次；纸张网格只在送纸量变化时重算；全屏程序只重画变化的格子；悬浮播放器只在播放时每秒重绘 ≤30 次。
- 使用时间预算限制活动帧率为 60、空闲为 30，独立于 144/240 Hz 等显示器刷新率；容忍 Chrome 偶发约 2 ms 的提前 RAF 时间戳，避免额外丢帧。隐藏页面停止三维绘制，通过 visibilitychange 重置采样，恢复后不把后台停留时间当作性能下降。
- 默认自动中画质，连续 3 秒活动渲染平均帧间隔大于 27 ms 时切低；手动档位不受自动调整影响。高/中/低像素比上限分别为 2/1.25/1，实际画布像素预算为 400/160/90 万，阴影尺寸为 4096/2048/1024。
- 高画质保留描边、泛光、4× MSAA；中画质取消 HDR 缓冲 MSAA，泛光首层降为实际画布宽高的 1/4；低画质跳过额外的法线描边场景绘制，并关闭泛光与颗粒，保留卡通材质和暖色调。
- 阴影贴图只和太阳与投影物有关、与相机无关：动态场景按高/中/低最多每秒 30/15/10 次更新，其余时间每秒约 6 次；小零件不投影；吊篮绿萝合并成 9 个网格。
- 0.2.1 同机对照：1280×720 视口、DPR 2，演示打字分别采样 2 秒；旧默认高画质 1181 次绘制/帧、GPU 16.3 ms，新默认自动中画质 604 次绘制/帧、GPU 5.2 ms，两者约 60 fps。来自 Mac 应用内 Chromium 的 WebGL 计时查询，非 Windows RTX 5060 实测；数值会随设备、视口、画质和场景变化。

## 13. 近似与未做的

- 原创造型，非实机复刻；所有尺寸与时间为调校值。
- 纸张：参数化路径 + 编排动画，不是布料/薄板物理；没有纸张自碰撞；落桌位置固定在桌面左侧。
- 窗外街景是风格化的绘画，不对应真实地点；绘制层是圆柱面，贴近窗户、斜着看到很偏的角度时能看出“画”的感觉。
- 全屏程序直接显示在纸上属于数字扩展。
- 猫是程序建模的，没有骨骼动画（呼吸、耳朵、尾巴、抬头都是整体变换）。
- 音乐和图片只存在当前浏览器（IndexedDB）；换浏览器或清除网站数据会丢失。
- 中文等字符是数字扩展，借用字杆动作。
- 主机信任只在会话内固定；没有持久的 known_hosts。
- 移动端触屏输入、低端 GPU、长时间运行未测。
