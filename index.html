      音乐

      还没有音乐点“添加音乐”，选择电脑里的音频文件

        音乐只保存在这台设备的浏览器里（IndexedDB），不会上传。支持 mp3、m4a、ogg、wav、flac（取决于浏览器）。墙上那块悬浮的玻璃播放器也能直接点。

        LOCAL CONNECTION

        连接你的设备

        1. 在项目目录安装依赖并启动本机服务：
          npm install
npm start
        2. 打开服务实际打印的 http://127.0.0.1:端口 地址。
        3. 填写本地访问口令和你的 SSH 设备信息，核对主机指纹后连接。

        在线演示不会接收密码或私钥。
